# FARM 123

FARM 123 is a gamified interactive mathematics learning mobile application designed for preschool children aged 4–6. It aims to make early mathematics learning more engaging and enjoyable through a fun farm-themed environment.

The application features three learning modules: **Counting, Addition, and Subtraction**, each consisting of multiple levels and interactive activities. Children can earn animal-themed badges as they progress through the activities.

Built using **Flutter** and **Firebase**, FARM 123 provides a child-friendly learning experience with interactive visuals, audio guidance, and progress tracking to encourage independent learning.
